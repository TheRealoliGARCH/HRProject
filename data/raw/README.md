# Raw data

This directory is reserved for source-derived observations.

Rules:
1. Do not overwrite source observations during cleaning.
2. Store source metadata alongside every dataset.
3. Preserve the source definition of each variable.
4. Record retrieval date and source URL.
5. Never replace a missing value with zero without explicit source evidence.
6. Keep organization-level observations separate from aggregate benchmark statistics.

Large source files may be stored outside Git when licensing or repository-size constraints require it; in that case the source registry must contain a stable identifier and retrieval information.
