# Organization-Level Source Acquisition

PR #6 records the first verified organization-level source evidence for the Paper 3 acquisition stage.

## TCS evidence

The initial verified organization is Tata Consultancy Services (IND001).

The FY 2018-19 TCS Corporate Sustainability Report contains an exhibit reporting the break-up of new hires by region, employee age, and gender. The evidence is stored as a source-level record in metadata/organization_source_evidence.csv. The reported measure is a percentage distribution, not a count of hires, so it is not inserted into the employee-flow count fields.

The FY 2024-25 Integrated Annual Report reports workforce composition and an IT-services attrition measure. These observations are retained using their source-defined concepts.

## Screening outcome

TCS is recorded as Secondary rather than Eligible for the primary panel at this stage. The verified source set establishes group-specific hiring distribution and workforce composition, but it does not establish group-specific firing counts for a common observation window.

## Measurement discipline

- A percentage distribution of new hires is not converted into a hire count.
- Attrition is not relabeled as firings.
- Missing group-specific firing information remains missing.
- Source terminology and reporting periods are retained.
- Screening status is determined by evidence availability, not by the observed magnitude or direction of flows.

## Acquisition boundary

This PR records verified source evidence; it does not claim that a complete organization-level Paper 3 panel has been acquired. Further organizations and source periods must be screened using the same rules.
