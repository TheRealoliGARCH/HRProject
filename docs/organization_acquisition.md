# Organization-Level Source Acquisition

PR #6 recorded the first verified organization-level source evidence for the Paper 3 acquisition stage. PR #8 adds a second organization-level evidence package for Infosys (IND002).

## TCS evidence

The initial verified organization is Tata Consultancy Services (IND001).

The FY 2018-19 TCS Corporate Sustainability Report contains an exhibit reporting the break-up of new hires by region, employee age, and gender. The reported measure is a percentage distribution, not a count of hires, so it is not inserted into the employee-flow count fields.

The FY 2024-25 Integrated Annual Report reports workforce composition and an IT-services attrition measure. These observations are retained using their source-defined concepts.

TCS remains **Secondary** because the verified evidence set does not establish group-specific firing counts for a common observation window.

## Infosys evidence

The official Infosys Sustainability Report 2018-19 reports total counts and rates of new employee hires by age, gender and region. It also reports total counts and rates of employee turnover by age, gender and region. The verified records include the reported group-specific counts.

The later Infosys Integrated Annual Report 2024-25 reports workforce composition and source-defined turnover rates. It does not establish group-specific firing counts for the required common observation window.

Infosys is recorded as **Secondary**, not Eligible, because the verified evidence set does not establish group-specific firing counts for a common observation window.

Wipro defines this as voluntary attrition and it is retained as a source-defined turnover concept rather than a firing measure. ## Measurement discipline

- Source-reported hire counts are retained as counts.
- Source-reported turnover counts remain turnover counts.
- A percentage distribution is not converted into a count.
- Turnover and attrition are not converted into firings.
- Missing group-specific firing information remains missing.
- Source terminology and reporting periods are retained.
- Screening status is determined by evidence availability, not by flow magnitude or direction.
